# problem 2; titled "Problem J2: Olympic Scores."

the second problem in the contest is called olympic scores, and was a slightly more difficult problem than the first one utilizing some arrays skills, with 5 judges judging an athletes score at the olympics all with different scores.
the purpose here was to sort their 5 values into a sorted array, and pulling out the min/max values to eliminate one occurence of both the lowest and highest scores, then adding the rest of the score values in the array and multiplying it by the events difficulty factor.
i utilized a specific method to increase efficiency and the speed of completing the problem much faster instead of using for loops to pull out values, i used arraySort to immediately sort the inputed values allowing me to directly pull the max and min elements without for loops.
