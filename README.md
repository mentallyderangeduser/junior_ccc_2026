# junior_ccc_2026; my attempt at the junior ccc
this repo is dedicated to my attempts and succesful solutions within doing the 2026 junior canadian computing competition.
the code for problems J1 thru J4 are all uploaded. unfortunately, due to time, i was unable to complete problem J5.
i had lots of fun doing this contest, and it really challenged me in ways that i did not assume in Java!
more information about the contest is available on the university of waterloo's website at https://cemc.uwaterloo.ca/contests/ccc.
all problems and descriptions in detail are able to be seen at https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026CCCJrProblems.html.
the general commentary and solutions for the 2026 junior contest are able to be seen at https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026CCCJrCommentary.html.
