# problem 1; titled "Problem J1: Concert Tickets."

the first problem in the contest is called concert tickets, and it was a very basic java program that made me determine whether a person named Besa is able to buy concert tickets based on the number of tickets that they want to buy represented by B, the total number of concert tickets represented by T, and the number of tickets others have purchased represented by P.
the general solution to this was a general condition shown by B + P > T, by printing N when the condition was true, and printing y followed by the value of T - (B + P) when the condition was false.
